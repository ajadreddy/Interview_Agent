# Preliminary Two Sum baseline observations

These observations come from inspecting the 40 real local Ollama replies in `baselines/2026-10-20/report.json`. They are **not human-reviewed labels** or automatic semantic scores. The deterministic result is 40 successful API replies, 31 passing and 9 failing the specified format, tool, and transition checks.

- **Leading optimization cue:** `approach-03`, `approach-05`, `hint-01`, and `hint-03` received the same O(1)-lookup suggestion. In `approach-05`, the candidate had already given a valid sorting approach with original indices and correct complexity. The model diverted them toward a hash lookup instead of letting them implement it. The deterministic checker flags the missing coding transition, but not the hint leakage itself.
- **Misconception detection:** `misconception-01` did not probe the insert-before-check same-index bug; it asked a generic map-storage question. `misconception-04` responded to a false O(1)-space claim by explaining complement lookup, leaving the space misconception unresolved. `misconception-06` ignored the candidate's multiplication misunderstanding and asked about O(1) lookup instead.
- **Coding evidence:** No tool call was captured in any of the 40 replies. `coding-01`, `coding-02`, and `coding-03` required inspection of the supplied code snapshot and failed that check. A separate smoke run of `coding-01` even said there was no implementation although code was present in state. The route exposes code through `read_current_code`, so a fluent answer alone cannot establish that the model used it.
- **Progression:** `progress-03` explained the one-pass map mechanism, no-self-reuse invariant, and O(n)/O(n) cost, yet the model asked again how complement lookup works instead of sending the coding transition. `coding-04` asked another edge-case question after a correct answer to a passing-code review, rather than closing the segment.
- **Some memory behavior worked:** `memory-01` and `memory-02` emitted the coding transition after sufficient prior reasoning; `memory-05` and `memory-06` closed passing reviews after the candidate answered. The fixed-history design makes those successes distinguishable from shallow one-turn replies.

The current report has no full semantic-judge pass/fail totals. A one-case Ollama judge smoke run returned valid JSON, but its rationale included an unsupported reading of the conversation. Use an independent judge model and sample its evidence before relying on automatic semantic counts.
